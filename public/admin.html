这是什么

这是一个「假 LLM API 服务」的控制台：所有接口的返回内容都由你在这里写死，服务不会调用任何真实大模型。

客户端只要把 base_url 指向本站，就能像调用 OpenAI 一样拿到你写的内容。规则命中优先级：正则 > 关键词 > 模型名 > 兜底规则。

响应规则

编辑规则

从左侧选一条规则，或点「新建规则」。

可用占位符

写在响应内容里，返回时会被替换成真实请求数据：

{{user}} 用户最后一句 · {{messages}} 全部对话
{{model}} 模型名 · {{id}} 本次请求 id
{{time}} 时间 · {{hash}} 消息指纹
{{rand}} 随机串 · {{len}}/{{words}} 字数
{{path}}/{{method}} 请求路径与方法 · {{key}} 客户端 key

用法

        
curl https://HOST/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-anything" \
  -d '{"model":"fake-gpt-4o","messages":[{"role":"user","content":"你好"}]}'

        
流式：请求体加 "stream": true。任意其它路径也会返回规则内容，调试用 /v1/echo。
