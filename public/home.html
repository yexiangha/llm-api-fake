它是怎么工作的

一张 Cloudflare KV 表 + 一个 Worker。后台里每条规则写清「匹配什么」和「回答什么」： 正则 / 关键词 / 模型名三种匹配方式，外加一条兜底规则；响应内容里可以用 {{user}}、{{model}}、{{time}}、{{hash}} 这类占位符把真实请求信息编进假回复里。

Built with Cloudflare Workers · KV · Wrangler · 管理后台 · 本服务仅用于测试、演示与教学，请勿用于冒充真实模型服务。
